Gezsk Ai Workspace

Không gian làm việc kết nối agent, skill và các API AI của bên thứ ba (ví dụ: Anthropic API) thông qua một backend trung gian — để trình duyệt của người dùng không bao giờ cần biết đến API key thật.

Biểu tượng ^_ — điểm chèn lệnh đang chờ, ẩn dụ cho một hệ thống luôn sẵn sàng thực thi.

Kiến trúc hệ thống

Nguyên tắc cốt lõi: API key của bên thứ ba chỉ tồn tại trên server của bạn, không bao giờ xuất hiện trong mã nguồn frontend, kể cả ở dạng comment hay biến ẩn.

Yêu cầu đi qua backend — API key (chấm màu hổ phách) chỉ di chuyển ở chặng phía trong, không bao giờ tới trình duyệt.

Tính năng cốt lõi

Ba khối chức năng đứng độc lập nhưng chia sẻ chung một backend — mỗi khối mở rộng được riêng khi dự án lớn dần.

Agent runtime

Điều phối nhiều agent chạy song song, mỗi agent gọi backend riêng để lấy kết quả từ mô hình AI.

Thư viện skill

Skill được nạp theo yêu cầu, đóng gói quy trình lặp lại thay vì viết lại logic mỗi lần.

Nhật ký & giám sát

Mọi lệnh gọi đi qua backend đều được ghi log — theo dõi chi phí và lỗi theo thời gian thực.

Thiết lập backend (Node.js)

Cài biến môi trường trên server — không đưa vào commit hay file public.

.env
THIRD_PARTY_API_KEY=your_actual_key_here

# Biến môi trường phía server, KHÔNG commit lên git

THIRD_PARTY_API_KEY=your_actual_key_here

server.js 
// Backend gọi API bên thứ 3 — key đọc từ biến môi trường
app.post('/api/chat', async (req, res) => {
  const r = await fetch('https://api.example-provider.com/v1/messages', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${process.env.THIRD_PARTY_API_KEY}` },
    body: JSON.stringify(req.body)
  });
  res.json(await r.json());
});

Bảo mật API key

  • Không bao giờ đặt key thật trong HTML, JS phía client, hay commit git.
  • Luôn gọi API bên thứ 3 từ backend, trả kết quả về client qua endpoint riêng.
  • Dùng biến môi trường (.env) và thêm vào .gitignore.
  • Xoay vòng (rotate) key ngay nếu nghi ngờ bị lộ.

Quy mô & hạ tầng

Backend trung gian được thiết kế để đứng vững khi số agent tăng lên — không đổi kiến trúc, chỉ thêm tài nguyên.

1
backend, nhiều agent
0
API key lộ ra client
∞
agent mở rộng theo hàng ngang

Mỗi tick = một request được backend trung chuyển. Không có giới hạn cứng — chỉ giới hạn theo hạn mức của nhà cung cấp API và cấu hình rate-limit bạn đặt.
