Developer documentation

Đây là cổng tài liệu tổng hợp. Các liên kết tới package, endpoint hoặc repository cụ thể sẽ được bổ sung theo trạng thái phát hành thực tế; không giả định API chưa được công bố là đã khả dụng.

01 / GET STARTED

Bắt đầu trong vài phút

Chuẩn bị môi trường, lấy mã nguồn và chạy dự án cục bộ. Hãy kiểm tra README của từng repository để biết yêu cầu runtime chính xác.

Chuẩn bị môi trường

Cài đặt Git và Node.js phiên bản LTS phù hợp với repository bạn muốn chạy.

TERMINAL / CHECK ENVIRONMENT
node --version
npm --version
git --version

Clone repository

Chọn repository trong tổ chức zskbot hoặc OCodejs và clone về máy.

TERMINAL / GIT
git clone https://github.com/zskbot/ocodejs-cli.git
cd ocodejs-cli

Cài dependencies và chạy

Với dự án Node.js có package.json, cài dependencies rồi chạy script được khai báo trong package.

TERMINAL / NPM
npm install
npm run [script]

06 / PLATFORM

Kiến trúc hệ sinh thái

Tách biệt lớp giao diện, công cụ phát triển, dịch vụ tích hợp và hạ tầng triển khai. Mỗi repository là nguồn sự thật cho chức năng mà nó sở hữu.

LAYER 01

Developer Experience

CLI, SDK, templates và các công cụ hỗ trợ quy trình phát triển.

LAYER 02

Application Layer

Web app, dashboard, editor và các trải nghiệm người dùng.

LAYER 03

Integration Layer

API, MCP servers, OAuth và các kết nối với nền tảng bên ngoài.

LAYER 04

Infrastructure

07 / DELIVERY

Deploy & Preview

Quy trình khuyến nghị cho thay đổi tài liệu và ứng dụng: làm việc trên branch riêng, tạo Preview, kiểm tra trên desktop và mobile rồi mới xem xét phát hành.

Branch-based changes

Tạo branch riêng cho mỗi thay đổi; không chỉnh trực tiếp nhánh phát hành.

Preview validation

Kiểm tra route, link, responsive layout, console và nội dung trước khi merge.

Release with approval

Chỉ phát hành sau khi review, xác nhận phạm vi và kiểm tra cấu hình môi trường.

09 / COMMUNITY

Find an issue

Open a pull request
